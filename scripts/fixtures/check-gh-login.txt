# Cases of scripts/check-gh-login.sh, read by scripts/test-check-gh-login.sh.
#
# One case per line, four fields separated by ' | ':
#
#   <pass or fail> | <what the output holds, or -> | <name> | <tree>
#
# A run exits 0 for pass and 1 for fail. The second field is '<key>', then ' @ <subject>' for each
# datum the line names, such as a host path. A line of the output ends in '[<key>]', the rule and a
# reason word, and holds each subject, in that order and with no ASCII letter, digit, hyphen, or
# underscore beside it; the rest of its wording is free. A field may start with '!': it then holds
# where no line that ends in '[<key>]' holds the subjects in their order.
#
# A line that starts with '#' is a comment, not a case. Any other line that is not blank and not a
# case fails the self-test, named.
#
# The tree is a list of steps separated by '; ', or '-' for none, applied in order to a directory,
# not under git, that passes the check, of one file, .devcontainer/devcontainer.json:
#
#   {
#     "name": "fixture",
#     // The login of the GitHub CLI.
#     "mounts": [ "<mount>" ],
#     "image": "mcr.microsoft.com/devcontainers/base:debian"
#   }
#
# where <mount> is 'source=${localEnv:HOME}/.config/gh-devcontainer,target=/home/vscode/.config/gh,
# type=bind', on one line. The steps:
#
#   mounts <text>   the line of "mounts" is '  "mounts": <text>,', or no line for '-'
#   line <text>     a line '  <text>' before the line of "image"
#   rm <path>       the path removed, a directory with all it holds
