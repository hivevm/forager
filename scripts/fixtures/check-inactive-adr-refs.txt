# Cases of scripts/check-inactive-adr-refs.sh, read by scripts/test-check-inactive-adr-refs.sh.
#
# One case per line, four fields separated by ' | ':
#
#   <pass or fail> | <what the output holds, or -> | <name> | <tree>
#
# A run exits 0 for pass and 1 for fail. The second field is '<key>', then ' @ <subject>' for each
# datum the line names, such as a file and line or an identifier. A line of the output ends in
# '[<key>]', the rule and a reason word, and holds each subject, in that order and with no ASCII
# letter, digit, hyphen, or underscore beside it; the rest of its wording is free. A field may start
# with '!': it then holds where no line that ends in '[<key>]' holds the subjects in their order.
#
# A line that starts with '#' is a comment, not a case. Any other line that is not blank and not a
# case fails the self-test, named. An identifier is written with a colon after its category, as
# 'SEC:decision-1', and read with a hyphen in its place, so that no check reads this table as
# citing it.
#
# The tree is a list of steps separated by '; ', or '-' for none, applied in order to an empty
# directory, not under git. The steps:
#
#   adr <id> <status>      the file docs/adr/<id>.md, exactly '# <id>: decision\n\n- **Status:**
#                          <line>\n', the line '🟢 accepted' for 'accepted', '🟡 proposed' for
#                          'proposed', '🔴 rejected' for 'rejected',
#                          '⚪ superseded by [<new>](<new>.md)' for 'superseded:<new>', and
#                          '⚪ superseded' for 'superseded'
#   category <key>         the line '- **<key>** — a category.' appended to docs/adr/README.md,
#                          which starts with the line '### Categories'
#   text <file> <text>     the text appended to the file as one more line; the file and its
#                          directories are made when absent
#   git                    the directory made a git repository, every file it does not ignore
#                          staged
